# Cheatsheet

## Fast Diagnosis

| If you see | Suspect | Use |
|---|---|---|
| A fluent, obvious answer | System 1 story | Ask what is missing |
| A vivid example driving risk | Availability | Compare frequencies |
| An initial number shaping estimates | Anchoring | Independent base estimate |
| A stereotype-like case description | Representativeness | Start with base rates |
| Extreme performance | Regression neglect | Expect movement toward mean |
| A confident expert in a noisy domain | Validity illusion | Check feedback and track record |
| A plan with no comparable failures | Planning fallacy | Outside view |
| Reluctance to sell or switch | Loss aversion / endowment | Make opportunity costs explicit |
| Different choices under equivalent wording | Framing effect | Reframe both ways |

## Decision Rules

- If evidence is vivid but sample size is small, downgrade confidence.
- If a prediction is based on a story, ask for the reference class before adjusting for the story.
- If an expert intuition is offered, trust it only when the environment is regular and feedback is fast and repeated.
- If losses are evaluated one by one, switch to a broad frame before rejecting positive expected-value risks.
- If a group is evaluating people or projects, collect independent judgments before discussion.
- If a project feels exciting and uniquely promising, run a premortem and get outside-view data.
- If happiness is being evaluated, separate momentary experience from remembered life narrative.

## Prospect Theory Table

| Domain | Typical pattern | Watch for |
|---|---|---|
| High-probability gain | Risk aversion | Settling too early |
| High-probability loss | Risk seeking | Doubling down |
| Low-probability gain | Lottery seeking | Overpaying for upside |
| Low-probability loss | Insurance seeking | Overpaying for fear relief |

## Forecasting Checklist

1. What is the target question?
2. What easier question might I be answering?
3. What is the base rate/reference class?
4. How valid is the case-specific evidence?
5. How much should I regress toward the mean?
6. What would change my mind?
