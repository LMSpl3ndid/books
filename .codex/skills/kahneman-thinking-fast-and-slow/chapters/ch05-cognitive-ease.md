# Chapter 5: 你的直觉有可能只是错觉

## Core Idea
Treat ease as a signal, but verify it before treating it as truth. 熟悉、清晰、重复和好心情会制造认知放松，让陈述显得更可信、更顺畅。

## Frameworks Introduced
- **认知放松**: 熟悉、清晰、重复和好心情会制造认知放松，让陈述显得更可信、更顺畅。
  - When to use: 面对判断、预测、风险选择、评估他人或复盘结果时。
  - How: 先识别直觉给出的答案，再写出基准率、参照点、证据质量和可能的替代问题，最后让系统2校正。

## Key Concepts
- **熟悉性**: 本章用于解释判断或选择偏差的关键概念。
- **曝光效应**: 本章用于解释判断或选择偏差的关键概念。
- **好心情**: 本章用于解释判断或选择偏差的关键概念。

## Mental Models
- Use **系统1假设** when an answer arrives quickly, fluently, or emotionally.
- Use **系统2校正** when stakes are high, evidence is thin, or a base rate/reference class exists.
- Think of errors as predictable products of useful shortcuts, not as random stupidity.

## Anti-patterns
- **把流畅感当事实**: 顺畅、熟悉、具体或连贯的答案不等于正确。
- **忽略基准和参照点**: 只看个案故事会放大直觉偏差。

## Worked Example
重复出现的词、清晰字体和押韵表达更容易被判为真实，即使证据没有增加。

## Key Takeaways
1. 对“听起来对”的内容增加核查；重要材料要避免只因排版清晰、重复多次就被接受。
2. Ask what information is missing before accepting the first coherent story.
3. Translate the lesson into a checklist, rule, or reference-class comparison when decisions repeat.
